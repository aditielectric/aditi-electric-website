ADITI ELECTRIC — STATIC WEBSITE
================================
This is a static website for GitHub Pages. It has no dashboard, editor, database,
backend, upload feature, login, cart, checkout or payment processing.

FILES
- index.html
- style.css
- script.js
- assets/ (images bundled with the website)

BEFORE PUBLISHING
1. Replace every tel:+910000000000 placeholder in index.html and script.js with
   the shop's public phone number.
2. Verify the address and Google Maps pin before publishing.
3. Add the verified Google Business Profile review URL if you want a reviews button.
4. The site uses the existing shop/product images included in assets/.

PUBLISHING
Upload all files and the assets folder to the root of a GitHub repository,
then enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root).
